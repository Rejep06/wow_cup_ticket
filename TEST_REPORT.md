# Отчёт проверки v6

Дата: 18 ноября 2026 года.

## Выполнено

- `python -m compileall -q .` — успешно.
- `python watcher.py --help` — успешно.
- `TEST_BROWSER_PATH=/usr/bin/chromium python -m unittest discover -v` — **67 тестов, OK**, без пропусков в использованном окружении.
- Python 3.13, Playwright 1.57.0, системный Chromium для четырёх необязательных браузерных тестов.

Распределение:
- 35 тестов чистых правил: URL/Nuxt, event/date, схема v4/CDN, стоимость, соседние места, бюджет, backoff/Retry-After, локальный журнал, обезличивание.
- 12 тестов наблюдения за заказами: create не равно reserve, последовательность running → failed → cancel, другой order ID, неизвестный статус, preview не равно заказ, точный состав заказа.
- 13 асинхронных тестов транспорта/ограничителя отправки + 1 тест блокировки второго процесса.
- 2 теста управляющего сценария с имитацией браузера/сервера.
- 4 теста реального Chromium с локально подставленной HTML-страницей about:blank: контакты/корзина/СБП, платёжный заголовок не равен подтверждению, неизвестная разметка, отсутствие значений контактных полей в диагностике.

Браузерные проверки выполнялись без доступа к сети и без переходов на живой сайт. Ограничение по домену заменялось только внутри тестового UI-адаптера для локального about:blank. Производственный код разрешает действия только на виджете. Тесты проверяют механику селекторов, а не совпадение этих селекторов с текущей страницей WOW CUP.

## Не проверено

- Успешный живой резерв WOW CUP.
- Точная Request Payload-схема реального orders/create.
- Актуальные селекторы реальной корзины, согласий, новой СБП и QR-кода.
- Успешный reserve-статус реального виджета: варианты success/completed в положительных тестах синтетические.
- Доставка в Telegram с токеном пользователя.
- Отсутствие антибот-ограничений при интервале 10 секунд.
- Совместимость локального state.json с v3/v4/v5.

Ни одного реального заказа, резерва, отмены или банковского платежа во время разработки не выполнено. Прохождение локальных тестов не является доказательством готовности к автоматическому оформлению в production.
